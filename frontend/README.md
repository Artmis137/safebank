# Frontend

Ce dossier est réservé au client web ou à l'interface utilisateur du projet SafeBank.

## État actuel

Le dossier est vide. Il doit accueillir l'application frontend (React, Vue, Angular ou autre framework) ainsi que ses configurations de build et de déploiement.

## Rôle attendu

Le frontend sert de point d'entrée utilisateur pour :

- consulter les comptes,
- lancer des opérations de virement,
- afficher les résultats de la détection de fraude,
- interagir avec les services backend via un gateway ou des API.
