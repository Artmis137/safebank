# Hub

Le dossier `hub/` est dédié au point d'entrée applicatif ou au composant d'orchestration du système SafeBank.

## Rôle attendu

Le hub est généralement la couche qui :

- reçoit les requêtes externes,
- applique le routage vers les bons services,
- centralise la gestion d'API ou de gateway,
- sécurise les échanges entre utilisateurs et microservices.

## État actuel

Le dossier est vide. Il devra contenir le code et la configuration du gateway, du service d'API ou de l'orchestrateur applicatif selon le design final retenu.
