# Documentation SafeBank

Ce dossier contient les documents de cadrage et de suivi du projet.

## Documents présents

- `01_PROJET.md` : contexte du projet et objectifs fonctionnels.
- `02_TECHNIQUE.md` : aspects techniques et architecture logicielle.
- `03_SPRINTS.md` : planification des itérations / sprints.

## But du dossier

La documentation permet d'aligner :

- le besoin métier,
- l'architecture applicative,
- la planification technique,
- la mise en œuvre progressive par étapes.

## État du projet

Le dépôt suit un chemin de construction progressif : la base microservices est présente, mais l'implémentation reste à compléter selon les livrables décrits dans les documents.
